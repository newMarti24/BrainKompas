# BrainKompas
Edukativna web aplikacija za djecu s ADHD-om i disleksijom.
## Opis

Aplikacija je namijenjena djeci od 1. do 4. razreda osnovne škole. Cilj aplikacije je poticati pažnju, koncentraciju, pamćenje, prepoznavanje slova i razvoj predčitalačkih vještina.

Aplikacija je prilagođena djeci s ADHD-om i disleksijom kroz jednostavno sučelje, kratke upute, velike vizualne elemente, audio podršku i jasnu povratnu informaciju.

## Aktivnosti

- Riječi na isto slovo
- Zapamti 3 slova
- Klikni samo životinje
- Složi riječ

## Funkcionalnosti

- Odabir avatara vodiča
- Upis imena djeteta
- Lakša i teža razina aktivnosti
- Audio upute
- Vizualni prikaz zadataka
- Bodovanje
- Sustav zvjezdica
- Rezultat zadnje aktivnosti
- Ukupni rezultat
- Savjeti za roditelje
- Korisni linkovi za ADHD i disleksiju
- Postavke pristupačnosti
- Veći i manji font
- Svijetla i tamnija pozadina
- Uključivanje i isključivanje zvuka
- Uključivanje i isključivanje animacija

## Tehnologije

- HTML5
- CSS3
- JavaScript
